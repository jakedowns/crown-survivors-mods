What this measures. The kernel is shaped like Crown Survivors' hot loop: enemies chase the player, all-pairs separation, projectile travel and first-hit selection, damage application, edge respawns, contact damage. It is intentionally data-parallel and deterministic (no atomics, fixed loop order).

What this is not. It is not the authoritative game core. Boss behaviours, card choices, evolutions, walls, dash, and dynamic entity lifecycles remain branch-heavy and sequential. A complete WGSL port would duplicate the Rust core and risk parity drift; Engine D keeps WASM authoritative and uses the GPU where it actually wins.

Determinism. Same device + same dispatch order is run-to-run stable. Cross-vendor bit-exact parity is not guaranteed by f32 compute; if the GPU ever becomes authoritative, the kernel needs fixed-point math and a parity gate against the WASM core.
